# A hypothesis must name the result that would refute it

A claim that cannot specify, in advance, what observation would prove it
wrong is not falsifiable, and an unfalsifiable claim cannot really be
"tested": it can only accumulate confirming evidence while being
reinterpreted around anything that disconfirms it. Naming the refuter forces
the numeric threshold and the failure condition to exist before the data
does, closing off the retreat of moving the goalposts after a disappointing
result comes in. Pre-registration is incomplete without this line
written down explicitly ("if X happens instead, this hypothesis is
refuted"), not just the mirror-image statement of what would support it.

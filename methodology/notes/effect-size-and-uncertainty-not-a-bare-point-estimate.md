# Effect size and uncertainty must be reported, not a bare point estimate

A single point estimate ("accuracy went up") does not tell a reader whether an
effect is real or how much it matters: report the effect size (the magnitude
of the difference) together with an uncertainty figure (a confidence
interval, standard error, or credible interval) so the practical significance
and the plausible range of chance variation are both visible. A bare number
invites overconfidence, a two-point difference can look like "improvement"
when the actual noise band is ten points wide, and that gap matters most
exactly where the stakes are highest. Any claim graded above
`tested` on the empirical-robustness-standard must show the interval
alongside the number, not the number alone.
